# Cosmetics and community updates — 26 October 2026

- Increased the visibility of all card patterns, card outlines and nameplates. Light and dark themes preserve each item's chosen colour; nameplates have a dark backing for contrast. Shop try-ons and public/profile renderings share the same artwork variables.
- Accepted player connections show Unfriend. Either party can remove the connection; chat history stays intact and another accepted request is required before continuing that friendship's messages. Older accounts retain their existing open-conversation behavior until a connection is explicitly established or removed. Removing a friend remains possible when their direct messages are disabled.
- Community chat supports individual @username suggestions with prefix matching, keyboard selection and touch/click selection. Lookup returns at most eight public usernames per request, excludes blocked/suspended players, is authenticated and rate limited, and exposes no email addresses.
- Maximum five mention occurrences per message, enforced on HTTP and Socket.IO. @all, @everyone and @here are unavailable. Unknown or blocked usernames remain plain text. Mentions resolve on the server, persist with their message, render as safe profile links, and notify each eligible recipient once per new message subject to chat-notification preferences. Repeated occurrences do not create repeated alerts; idempotent retries do not create more alerts.
- Migration `20261026_chat_mentions` adds a JSON mention-span column with an empty-list default. Existing chat text and history remain unchanged. It follows `20261024_platform_controls` and uses the existing deployment migration command.

Verified with isolated PostgreSQL tests covering mention prefixes, privacy, limits, escaping, idempotent retries, deletion and unfriend permissions; existing chat inbox/outbox and friend-request regressions; and Node tests for mention parsing, preview isolation and carousel behavior. Local browser checks confirmed @B → three test users, @Bat → two, selecting/sending a linked mention, Unfriend → Add player, and 390px light/dark cosmetic layouts without horizontal overflow. Browser previews use synthetic accounts; no production messages or account changes were made. Production deployment is not verified by these local tests.
